# Debug Record

## Symptom
Observed vs expected behavior.

## Reproduction
Exact inputs/environment and whether deterministic.

## Evidence
Logs, stack, failing test, telemetry, or runtime observation.

## Hypotheses
List falsifiable hypotheses and how each was tested.

## Root cause
The mechanism that explains the symptom.

## Fix
Smallest permanent correction.

## Regression protection
Test/reproducer/check added.

## Verification
Evidence level and checks performed.

## Remaining uncertainty
Anything still not explained.
