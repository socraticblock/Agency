## Result

**V3.1 third-wave score: 33/48.**

V3.1 remains strong, but this pass exposes a real missing layer: explicit **boundary semantics**. The skill says to test boundaries, validate trust boundaries, and define contracts, but it does not force an agent to ask what a value *means* at those boundaries: units, range, precision, rounding, normalization, locale, canonical ordering, size limits, cache freshness, configuration defaults, or completeness of partial protocol data.

## Defects worth patching

- exact numeric/financial semantics;
- overflow/range and unit semantics;
- Unicode/locale/canonicalization semantics;
- test isolation and restoration of process-global state;
- safe configuration defaults and provenance;
- cache/source-of-truth/invalidation rules;
- resource budgets and bounded fan-out;
- protocol completeness/integrity;
- protocol-aware retry/rate-limit behavior;
- cleanup errors preserving the primary failure.

These are sufficiently general to justify a compact new reference rather than many one-off rules.
